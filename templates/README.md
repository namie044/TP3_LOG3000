# Dossier Templates - Interface Utilisateur

## Raison d'être

Ce dossier contient tous les templates HTML utilisés par l'application Flask Calculator. Les templates définissent la structure et le contenu des pages web servies aux utilisateurs.

## Fichiers contenus

### - index.html

**Responsabilité:** Template principal de l'application - Interface utilisateur de la calculatrice.

## Dépendances

- **Flask:** Framework web qui rend le template
- **CSS:** Dépend de `/static/style.css` pour le style
- **Backend:** Communique avec `app.py` via les formulaires POST
