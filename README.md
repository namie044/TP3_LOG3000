# Flask Calculator

o Équipe numéro 44

o Objectif
Ce projet consiste à développer, documenter et stabiliser une application d'une calculatrice construite avec Python (Flask).  
L’objectif principal est de :
- Mettre en place un dépôt GitHub propre et bien structuré.  
- Documenter la base de code (frontend et backend).  
- Identifier et corriger les bogues existants.  
- Mettre en place un pipeline de tests et de déploiement.  

o Prérequis d’installation
- Un compte GitHub.
- Git installé localement.
- Python et pip installés.

o Instructions d’installation
- Cloner le dépôt GitHub : git clone 
- Lancer le server Flask : python app.py
- Accéder à l’application : http://127.0.0.1:5500/templates/index.html
